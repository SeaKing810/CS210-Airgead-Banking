# CS 210 Portfolio Artifact
## Airgead Banking Investment Calculator (C++)

### Overview
This project was developed for CS 210 and simulates an investment calculator that demonstrates compound interest growth over time.

The application allows users to input:
- Initial investment amount
- Monthly deposit
- Annual interest rate
- Number of years

The program then generates two financial reports:
1. Investment growth without monthly deposits
2. Investment growth with monthly deposits

This project demonstrates object-oriented design, financial algorithm implementation, formatted output, and structured program flow control in C++.

---

### Problem Being Solved
The purpose of this program is to help users visualize long-term investment growth using compound interest. Financial forecasting tools require precise calculations and clear presentation of data. This project reinforces the importance of algorithm accuracy and user input validation in financial software.
